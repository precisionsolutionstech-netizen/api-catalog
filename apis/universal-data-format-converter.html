Universal Data Format Converter API

Convert JSON to CSV, CSV to JSON, XML to JSON, and more — plus Markdown → HTML, Markdown → PDF, and HTML → Markdown. One API for structured data (JSON, XML, CSV, Excel, YAML, …) and documents (Markdown, HTML, PDF). Stateless, 20MB max. Deterministic output.

Last updated: June 28, 2026

Subscribe on RapidAPI Plans and quotas: confirm on the live RapidAPI listing (indicative tiers below).

One URL: POST /convert on universal-data-format-converter.p.rapidapi.com — JSON body, raw Content-Type/Accept, or multipart file upload (no base64 required).

🎉 What’s new — Document conversion (v2.1)

Markdown ↔ HTML ↔ PDF is here! Upload a .md file and get a beautiful, self-contained HTML page (CSS embedded — one file, ready to open or share) or a polished PDF document. Convert full HTML pages back to Markdown with three modes: strict, readable, and llm-friendly — the same capabilities as a dedicated HTML-to-Markdown API, now on this endpoint.

GFM support: tables, task lists, fenced code with syntax highlighting, strikethrough, footnotes, blockquotes, and more. HTML output uses GitHub-style themes (github-light / github-dark). PDF uses fast server-side rendering — no Chromium required.

Try it: In the playground below, choose markdown → html or upload a .md file. Or paste HTML and convert to markdown with your preferred mode.

Also: Multipart file upload for Excel, CSV, JSON, Markdown, and more — pick a file, choose output format, run. Set form field from=html when uploading a full HTML page for markdown output (default .html is table extraction).

Why use this API?

Need to convert JSON to CSV for Excel? CSV to JSON for APIs? XML to JSON or JSON to XML for legacy systems? Excel to JSON or YAML to JSON for pipelines? Legacy systems use XML. APIs return JSON. Spreadsheets use CSV and Excel. Data pipelines use YAML, NDJSON, and more. Instead of building custom converters for every integration path, use one endpoint for all supported conversions.

Request & response schema

Three ways to call the API: raw body (Content-Type + Accept), JSON body (from, to, data), or file upload (multipart).

Input & output options (defaults)

Options are nested under options.input.{format} and options.output.{format}. Use the playground below to see and configure options for each format. Only include options you want to override.

Option keys use camelCase — e.g. sql-insert → options.input.sqlInsert, query-string → options.output.queryString.

Go to playground to select from/to format and see all available options with defaults.

    const key = 'YOUR_RAPIDAPI_KEY';

// 1) Extract tables from PDF
const form = new FormData();
form.append('file', pdfFile); // your PDF File object
const extractRes = await fetch('https://pdf-table-extraction-api.p.rapidapi.com/extract', {
  method: 'POST',
  headers: { 'x-rapidapi-key': key, 'x-rapidapi-host': 'pdf-table-extraction-api.p.rapidapi.com' },
  body: form
});
const extracted = await extractRes.json();
const rows = extracted.tables?.flatMap(t => t.rows ?? []) ?? [];

// 2) Convert JSON to CSV (or excel, xml, etc.)
const convertRes = await fetch('https://universal-data-format-converter.p.rapidapi.com/convert', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'Accept': 'text/csv', 'x-rapidapi-key': key, 'x-rapidapi-host': 'universal-data-format-converter.p.rapidapi.com' },
  body: JSON.stringify({ from: 'json', to: 'csv', data: rows })
});
const csv = await convertRes.text();
